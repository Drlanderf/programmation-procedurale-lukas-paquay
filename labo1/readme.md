# Labo 1 - Dev Profile

## Description

Ce projet consiste à réaliser une application en langage C permettant de présenter mon profil de développeur.

L'application permet de consulter :

- Mon profil
- Mes compétences
- Mes projets
- Mes statistiques

Les données du profil sont stockées dans un fichier `data.txt` afin de séparer les données du code.
